# INVAR全部实验结果与发现

核查日期：2026-10-29，新加坡时间。依据冻结旧阶段结果，以及本次重新抓取并核验哈希的第四阶段完整结果。本文将“实验跑完”“评分复算通过”和“科研假设得到支持”分别说明，不预设方法成功。

**目前最有证据支持的结论：模型知道规则、行为不受表达干扰、能够按照目标正确行动，是三件不能相互替代的事。直接训练表达一致性有局部收益，但迁移依赖来源、模型和训练种子，还没有形成通用修复方法。**

## 实验是否完成

第四阶段48次新训练、52项生成评估、17,014,784条新回答全部完成，52项通过远端独立标量复算。两条GPU队列正常结束，无失败标记或代码哈希差异，保留无关服务。全矩阵为2款模型×4个来源留出×3个训练种子×SFT/JS，共24组同曝光双臂比较、6个完整模型×种子块。

本次正在补齐最后一批大文件同步及本地原始回答独立复算；最终本地验收以本目录final_local_acceptance.json为准。此前本地已验收40项。本文全部新增汇总已对照远端独立实现记录，并独立重算来源权重、三种子均值与全部方法差值。小型快照528文件逐SHA通过，见snapshot_inventory.json及summary_arithmetic_audit.json。不要把小型汇总复核冒充新增原始回答已全部本地重算。

## 我们究竟测什么

可以把它想成一个社会决策测试：同一笔钱、同样的规则，只把清单改成表格，模型是否改变选择？如果规则真的变了，模型是否理解变化？如果明确要求最大化自己的收益，模型能否选对？

| 检查 | 通俗含义 | 判断方式 |
|---|---|---|
| 表达差异E | 意思没变，换个写法，选择分布变了多少 | 较低更稳定；不是答错题的比例 |
| 条件效应偏差G | 换个写法后，对“规则改变带来的影响”得出的结论差了多少 | 较低更少依赖表达 |
| 事实正确率U | 能否答对已改变和仍未改变的规则事实 | 两类分别报告 |
| 目标正确率Q | 明确给定目标后，行动是否属于正确选择 | 只对可完整求解的题评分 |
| 条件响应R | 社会条件变化后，行动分布改变多少 | 仅描述，没有统一越大越好 |

自由选择没有统一正确答案，不把更合作、更自利或更公平直接当成正确行为。比如模型始终贡献5，不应仅因不受表达影响就称它可靠，也不能没有依据地把贡献5判为道德或行为错误。

数据来自4项原研究，涵盖分配、最后通牒、信任返还、序贯合作、公共物品、第三方惩罚6类任务，构造92组条件比较、8,666份去重输入。数百万次回答主要来自重复采样与方法重复，不是数百万个独立情境。

## 每类方法得到什么结果

| 方法 | 实际做法 | 完整结果的判断 |
|---|---|---|
| 提示核对 | 提醒模型检查角色、权限、规则、收益 | 没有跨模型共同改善；加一句“仔细检查”不足以解决 |
| 模型先整理材料 | 先提取信息，再看原文加整理或仅看整理作答 | 有时提高目标正确率，但会遗漏或提取失败，稳定性不普遍提高 |
| 保守输入归一化 | 固定模块顺序，把严格可识别的表格变成清单 | 低成本有效的局部工程处理，Qwen14最明显；有事实/目标小幅代价，未做完整跨来源新训练组合验证 |
| 激活投影 | 抑制等价表达对应的隐藏状态差分，另设条件方向保护版 | 在已测设置下无共同而明显的真实生成修复；部分来源只测事实，不能夸大覆盖 |
| 表达偏移校准 | 从训练来源估计格式偏移，再校正候选分数 | 行为/目标实际覆盖为0，属于当前实现覆盖不足，不能宣布这类技术已被证伪 |
| 普通监督训练SFT | 教模型做事实题和有正确答案的目标题 | 开发集正确率明显提高，但表达稳定性可能变差；最新迁移收益依模型/来源而异 |
| 监督题一致性 | 让等价表达的事实/目标题预测接近 | 初步开发有缓解，未形成普遍修复；与自由行为JS是不同约束 |
| SFT+自由行为JS | 在相同社会条件下，让不同表达的自由行动分布接近 | 开发集收益很大，扩大验证后存在清楚的改善与失败边界 |
| 条件教师KL及JS+KL | 用冻结原模型按条件形成软参照，限制训练漂移 | 开发复测中不优于JS单独使用，目标正确率有约4个百分点代价；没有证据支持约束越多越好 |

信息整理的预定证据校验失败回退率为Qwen3约41.44%、Qwen14约20.68%、GLM约24.17%，全部保留，未重抽到成功。

高精度归一化例子：Qwen14的E从0.10395降到0.04539，但Q从62.86%到62.10%；Qwen3模块顺序归一化E从0.03450降到0.02646；GLM从0.02840降到0.02108。它们是已知模板与固定开发集合的处理收益，不代表理解问题已消失。

## 为什么早期JS看起来特别成功

在高精度12组开发比较中，Qwen3同曝光SFT到JS，E为0.05553→0.01305，G为0.09026→0.02504，Q为88.34%→88.41%。四种训练臂看了同样材料和同样次数，排除了仅因多看题的解释。但这一总体包含训练接触材料，且只有一个训练种子，不能直接解释为来源迁移能力。

把这两个旧适配器扩到全部92组后，JS相对SFT仍有大幅平均改善：E为0.062178→0.016857，77/92条件对下降；但其中公共物品的101,376次自由行为回答全部固定贡献5，E/G/R/熵均为0。剔除公共物品的事后诊断仍显示部分收益，所以不能把全部改善都归为固定输出；同时正式主表也不能删除这个来源。

这说明两点：开发收益确实存在；仅用低E/G给方法颁发“理解更可靠”的结论会出错。

## 最值得继续研究的发现

**1. 会答规则题，不等于会在决策中用规则。**

在分配例子中，模型可以正确回答“给得太少就双方清零”。但明确要求自身收益最大化时，正确行动需要达到门槛；若要求缩小分配差距，正确行动又不同。Qwen3的IGVOFO第三种子门槛事实题全对，而门槛条件中两个互斥目标各调用一次、两次都正确的经验估计仍为0%。这不是证明真实成功概率绝对为零，也不是同一条智能体轨迹，但足以表明平均事实成绩不能代替目标执行检查。

**2. 平均目标正确率提高，也可能隐藏更差的目标区分。**

Qwen14在IGVOFO三个种子里，JS都让E/G下降、平均Q提高约6.12/6.82/6.47个百分点；但变化事实正确率分别下降约1.27/1.57/1.95个百分点。互斥目标子集的独立两调用均正确估计却分别从48.60%降至39.14%、49.72%降至46.42%、48.83%降至44.30%。这些子集只涉及一个独裁者条件对，提示端点可共享，不能外推为所有目标执行的普遍退化。

**3. 表达稳定可以通过有用的理解，也可以通过忽略差异实现。**

旧适配器的公共物品固定5是直接例子。新留来源训练没有因此就被判定失败；应继续看事实、目标、熵、逐条件分布与尾部。输出更随机或更固定本身都没有统一优劣方向，R下降也不能单独判错。

**4. 跨来源迁移与训练稳定性，是方法真正的难点。**

同一固定方案，在问卷来源上两个模型三个种子都改善E/G，在议价惩罚来源上Qwen14却三个种子都恶化。Qwen3的HPVBG第三种子E为0.083147→0.105399，6/8条件对变差、没有一对改善；事实与角色仍全对。来源还与任务、角色、菜单共同变化，尚不能断言是某个社会心理机制导致失败。

**5. 均值变好、最坏案例变好、更多情境变好，是三种不同结论。**

早期SFT降低最坏条件对E，却让中等偏差更普遍，因此E均值上升、平方辅助量下降可以同时出现。最新来源权重又显示总体方向可变。可靠报告必须保留逐条件结果、尾部、失败来源和两种权重。

## 现在能支持怎样的研究结论

已经有一条明确、可审查的实证主线：社会决策可靠性由多种能力组成，单独优化事实/目标监督或表达一致性，会出现能力之间的分离、局部代价和迁移边界。与仅展示几个模型答错相比，现有证据包含匹配训练对照、真实生成、来源留出、多训练种子、跨模型以及保留的负结果。

目前不支持“找到普遍有效的新算法”“准确模拟真人”或“已证明能泛化到全新社会情境”。现有四来源已被观察，当前属于开发与回溯迁移。独立人工等价性审核仍有缺口；更强泛化论断需要新来源审计、冻结后确认。论文创新性还需对照相关工作，不能靠回答数量或JS/LoRA组件名称认定。

后续最有针对性的方向是：为事实理解与目标行动之间的脱节设计可验证诊断，并检验一种改进能否在保持表达稳定的同时保住规则和目标区分。新增约束或归一化组合应先冻结完整对照，不奖励自由行为必须自利、合作或R增大，不按现有成绩挑来源。
