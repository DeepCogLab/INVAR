# 社会认知专门模型扩展测评

冻结日期：2026-11-04（新加坡时间）。本轮使用既有正式 INVAR v2 数据，不改写历史数据、历史八模型回答或 `sources/`。远端独立目录：`/workspace/project_social_simulation/invar_social_cognition_runs/20261104`。

## 问题与解释边界

检验这些公开专门模型在 INVAR 的等价呈现稳定性、社会事实更新/保持、明示目标执行和角色绑定上的表现。允许优于、持平或低于通用模型，不预设负结果。自由行为没有唯一正确答案，R 大小没有统一优劣方向；稳定但始终答错不能解释为社会理解好。

Centaur/Minitaur/Centauri 的人类行为预测、SOTOPIA 的互动角色扮演和 Social-R1 的社会推理不是完全相同的训练目标。已有中文 INVAR 的分数只能支持这些冻结模型在本任务和接口下的迁移表现，不能据此断言社会认知建模整体无效。多数模型卡以英语为主；中文迁移、数值推理和指令遵循均可能影响结果。需要英语等义版本及人类行为分布才能进一步分离语言迁移与人类行为预测能力，本轮不凭空生成相应结论。

## 模型与比较

按底座参数规模 0.36B → 0.6B → 1B → 1.7B → 4B → 7B → 8B → 70B 顺序执行。每个适配器与其精确匹配的原底座都测；Social-R1 增加同规模 Qwen3 对照，Socio 与 Qwen3-8B 对照。共有12个专门模型、11个对照配置，共23个测评臂。

四个 Qwentaur 适配器声明 `unsloth/Qwen3-*-Base`，不能与已有 `Qwen3-*` 对话权重混配。执行时下载声明的 Base 仓库、固定实际解析出的 revision 并保存记录。已有权重只读，记录配置与 safetensors 内容哈希、软件版本、模板、随机种子和上下文长度。加载失败、底座错误、显存不足是工程/兼容性结果，不能计作社会认知错误。rsLoRA 的缩放在远端 vLLM 0.14.1 的 PEFTHelper 实现中明确支持。

## 每个测评臂

1. 工程先导：全部8,666个唯一提示各调用一次，结果只能作探索性描述，不据此剔除低分模型。
2. 无结构约束生成诊断：按任务类型和固定哈希排序各取12个提示，共60个；最多2,048新 token。Social-R1 使用允许思考及 `<think>/<Answer>` 的说明；其他模型保留原始问题。该诊断不是原论文任务的完整复现，也不能与主测评混池计分。标签格式失败不等同于内容答错。
3. 正式测评：逐项复用既有正式计划的提示、重复次数和批次结构，每臂421,504次，共9,694,592次正式调用；行为每提示256次、事实每选项顺序8次、目标16次、角色32次，另有127个提示的重复批次。先导和诊断单独保存，不并入正式分数。

主测评沿用温度0.7、top-p 0.95、top-k -1、128新 token、无重复惩罚、XGrammar合法JSON菜单。语法仅含输出字段和合法选项，不含正确答案、预期行为方向或人类数据。只将原始 messages 送入模型，评价标签保留在评分侧。相同提示/重复/批次的各新模型共用确定性种子；与旧模型的抽样种子不同，比较时不能声称逐次随机数完全相同。

Base认知预测模型使用系统文本与用户文本按原序拼接的普通续写；对话模型用原生模板；Mistral将系统和用户内容合并为一个用户消息。未改写题目内容，但普通续写是迁移接口，不宣称复现 Psych-101 原始实验输入。主测评关闭 Qwen 思考以保持既有接口，Social-R1 原生诊断独立检验允许思考的情况。上下文溢出直接停机，不截断材料。

## 评分与案例

全量完成且没有非法/截断输出时，在隔离目录调用既有 `score_v2.py`，不修改评分函数，保留评分器哈希。正式汇总按条件对等权，报告 E/R/G、事实与目标正确率、角色检查、来源与呈现细分；抽样区间仅描述固定题目下输出采样，不外推新来源。

另存按调用加权的工程任务摘要，明确不替代论文的条件对等权成绩。所有原始输出逐条保存，包含 prompt_id、重复编号、seed、完整文本、结束原因、token数、输入哈希和模型配置哈希。

事实、目标、角色失败候选：以提示为单位计算全部重复中的错误频率，每任务最多取5个不同条件对，按错误频率降序、提示哈希打破并列。保存候选总数、筛选规则、完整题目、标准答案、原文输出和重复次数。格式/截断与客观答案错误单独标示。先导1次失败不能称为稳定失败；未人工核验的条目标为候选。完整结果中应同时查看成功案例与底座对照，不仅展示极端反例。

自由行为案例以四元组的输出分布、等价呈现距离和条件效应方向为证据；单次不同行为不是客观错误。主图应说明案例是描述性选择，不能替代完整汇总和不确定性。
