# INVAR：跨家族、双语与推理设置稳健性扩展

本方案在新增科学回答生成前冻结。目的在于检验现有结论的边界；改善、无效、反转和交付失败均完整保留。旧实验和原始中文题库只读。本轮不追加一致性训练：当前最缺的是独立模型家族、语言与推理接口的证据，重复训练不能解决这些缺口。

## 要回答的问题

1. 先前 Qwen 的大幅目标执行改善，在一个新的 Qwen 尺度及其社会专门模型上是否重现？
2. 在其他家族，提高原生推理强度、或明确要求简短推理，分别怎样改变目标执行、事实理解和等价表述稳定性？三类干预分别报告。
3. 把同一题库译成英文后，结论的方向和专门模型相对底座的差异是否改变？这是翻译语言条件下的比较，不能归因于训练语言或文化。
4. 低表述差异是否同时伴随事实/目标正确，还是伴随固定行动、输出失败或抽样噪声？
5. 对互斥最优行动的规则变化，模型能否同时答对四元组全部四题？仅检查行动是否变化不足以证明正确。

## 模型与对照

| 检查点 | 家族/用途 | 两种设置 |
|---|---|---|
| Qwen3-8B | 通用指令模型、匹配锚点 | 原生 thinking 关闭 / 开启 |
| SocialR1-8B | Qwen3 系社会专门模型 | 同一原生开关 |
| GPT-OSS-20B | 独立推理家族，原生 MXFP4 权重 | reasoning_effort low / high |
| Llama-3.1-8B-Instruct | 通用指令模型 | 直接回答 / 简短逐步推理 |
| Mistral-7B-Instruct-v0.1 | 与 SOTOPIA 匹配的指令底座 | 同上 |
| SOTOPIA-π Mistral BC_SR LoRA | 第二家族的社会专门化实例 | 同上 |
| GLM-4-9B-0414 | 通用指令模型 | 同上 |
| Qwen3-8B-Base | 预训练基模，独立诊断 | 格式示例下直接回答 / 简短推理 |

共8检查点、5家族。不能把8行当作8个独立家族。GPT-OSS low 本身仍有推理，不是“关闭思考”。提示推理也不是模型原生思考开关。各模型两臂使用同一权重、采样规则与输出上限；跨模型的精度、预训练和接口不同，不据此估计统一思考效应或国家差异。

SOTOPIA 使用元数据指定的 Mistral v0.1、共同底座 tokenizer/template，以及原有 r8 q_proj/v_proj 适配器。已核验64个 B 矩阵均非零；运行时要求引擎成功加载 LoRA，逐回答核对请求的 adapter ID，并保存底座与适配器完整文件 SHA256。它代表固定共同接口下该 BC_SR 检查点的增量结果；不是原论文完整交互系统或推荐接口的最优表现。原适配器使用4-bit训练，其训练底座确切历史 commit 未被本地元数据记录，因此不能声称已恢复训练环境。当前两臂底座推理均为 BF16。

基模使用两个固定的、仅说明 JSON 格式的示例，不含博弈正确答案；结果单列，不能按与聊天模型相同的接口能力排名。

## 题库与英文质量

核心面板在原92条件对中按来源、任务和实质因子分层，以固定 SHA 排序选择32对，四来源各8对；选择不读取模型分数。保留 V1_table、V4_rules_table 两个等价表述变体，覆盖六任务。选择算法及完整 ID 在 panel_selection.json。未覆盖原全部表述变体，因此本轮不能声称验证了“当前情况前置”或匿名替换的跨语言效果。

每种语言的覆盖：

| 部分 | 条件对 | 四元组 | 去重输入 | 重复次数 |
|---|---:|---:|---:|---:|
| 自由社会行为 | 32 | 64 | 189 | 8 |
| 明确目标题 | 13 | 78 | 234 | 2 |
| 变化事实检查 | 32 | 128 | 384 | 1 |
| 不变事实检查 | 32 | 128 | 384 | 1 |
| 参数互斥最优诊断 | 20 | 24 | 96 | 2 |

核心目标的13对包括 HPVBG 8、IGVOFO 1、PIQ572 4、PGG 0；**目标部分不具来源均衡**。参数诊断来自已有参数确认题的互斥最优切片，覆盖五任务，各4条件对；own/total/equality分别12/4/8四元组。它不是新社会研究或完整40参数对复验。

核心每语言1191个去重输入；加参数96个，中英共2574。四元组引用共享输入时，只生成一次；评分按引用恢复各条件对，而不把去重时保留的 parent_pair 错当作唯一用途。

英文由 AI 按443个独立中文片段翻译。逐片段核对数值多重集、参与者编号、动作符号、输出字段和表格结构；另由 AI 复核收益、门槛包含关系、角色和信息限制。所有题的 output_schema 和完整最优行动集合保持一致。**没有独立人类语义认证**，数值一致也不等同语义等价。英文是中文题库的翻译版本，两个语言不是两套独立来源。翻译表、检查结果及输入/标签 SHA 一并冻结。

## 固定运行规则

- 8检查点 × 2语言 × 2设置；每检查点11760次，共 **94080次科学生成**。工程试跑单列，不混入分数。
- temperature=.7、top_p=.95、top_k=-1、n=1、输出上限4096 tokens、上下文8192；不做引导式 JSON 约束或按答案重试。
- 聊天模板只渲染一次，随后以显式 token IDs 输入，add_special_tokens=False，避免重复添加起始符。保存逻辑消息、渲染文本和 token IDs 的哈希及模板/权重身份。
- 试次使用模型/题目/设置/重复编号派生的独立固定种子；按固定 SHA 打乱混合语言、任务和设置。相同重复编号不代表相同随机轨迹。
- chunk 256、max_num_seqs 64、BF16（GPT-OSS保留其原生MXFP4）、单进程单模型。模型间不同时占卡。
- 只使用物理 GPU1，先验证 UUID `GPU-REDACTED`；GPU0既有服务不操作。CUDA_VISIBLE_DEVICES=1，因为当前 vLLM0.14.1的设备映射不接受 UUID 字符串。
- 开始顺序为 Qwen3、GPT-OSS、Llama、GLM、Mistral、SOTOPIA、SocialR1、Base，优先建立跨家族覆盖。科学队列从启动起最多24小时使用GPU。硬件兼容性失败或超时如实保留，不补选模型、不按效果选择重跑；若未完成，矩阵明确标记缺项。
- 预算依据独立阈值分配工程题的速度确定：完整高重复候选超出单卡一天预算，统一采用上表较低预算，并保留24小时硬截止。工程题不是科学题，无正确性筛选。预计时间是估计，非完成保证。

## 评分与不确定性

三项能力分别报告：E/G（自由行为的表述可靠性）、U（事实正确）、Q（按明确目标执行）。自由社会行为不设“正确的人类选择”；规则变化的自由行为差异 R 没有单调优劣方向。

E 为 AB/CD 的归一化一阶 Wasserstein 距离均值；G 为两种表述下条件效应均值之差的绝对值。沿用已审计的标量实现，并以独立分位数网格、向量 CDF 实现交叉核对。先在条件对内平均变体，再平均条件对；同时报告来源等权和任务等权。行为面板来源均衡，条件对等权与来源等权在构造上相同，不能当作新发现。按旧来源8/8/22/54比例重新加权只是一项构成敏感性，不能当作完整92对估计。

Q/U以**全部尝试**为分母，错误、越界、格式失败、截断均不计正确；Q接受完整最优集合，不把其中一个最优行动当作唯一答案。Q另列来源等权/任务等权口径。参数主要量为互斥最优四元组的四题全对率，不把多题概率乘积当作单题正确率。

解析只读取最终交付：原生 on 必须闭合输入已打开的 think 通道；GPT-OSS必须交付 Harmony final 通道；思考中的 JSON 不可救回分数；重复字段拒绝。两臂使用相同的末尾 JSON 规则，同时保存更严格格式指标。长度截断即失败，即使之前出现过 JSON。

E/G先列有效回答条件指标，并给出所有未交付结果可在[0,1]任取时的保守缺失界；不能把全部失败算成完美稳定。另报告各任务行动集中度、交付率、截断率和 token 成本。低E加低Q是能力错配证据，不能直接推断“不看题”或心理机制。

行为仅8次抽样，经验W1有明显有限样本噪声，因此它是新扩展中的探索性诊断，不能取代既有高重复全92对结果。预先报告同题奇偶拆半 W1 作为抽样噪声参照，并做500次共享prompt重采样：同一prompt的所有四元组引用共享一次重采样，不把引用当独立样本。给出固定面板、观测抽样下的经验敏感性范围；**不是校准置信区间、去偏估计或对新研究来源的推断**。不对四来源、少数家族做总体显著性宣称。

## 验收与交付

冻结绑定输入、标签、翻译、代码、种子、预算和规则。每检查点核验全部预期试次、无重复、哈希、随机种子、模板/输入身份后评分；保存原始文本、特殊通道、完整输出token IDs、退出原因和进度。每个完成检查点自动评分、运行独立数值核验并更新汇总；最终拉回原始回答、日志、权重身份和结果，验证SHA，不复制模型权重。

最终写作材料须分别列出：被新增证据支持的结论、需要收窄的结论、反例和未覆盖范围；不预写“思考解决问题”“专门模型普遍更差”或“英文复现全部现象”。不论结果方向，保留完成矩阵。
