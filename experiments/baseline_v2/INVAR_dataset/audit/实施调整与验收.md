# 本轮实施调整与验收记录

日期：2026-10-22；数据版本0.1.0。本记录说明实际构建结果，不将计划、AI复核或合成测试写成人类审核或模型实验。

## 1. 数量如何得到

原方案75组候选；核对原研究Table 1后加入18组已有收益条件的相邻比较；第三方惩罚有1组因舍入规则无法确认剔除。实际保留75＋18－1＝92组。新增条件在看任何模型输出之前选定，没有以模型是否失败为筛选依据。

92组中54组原条件比较、38组研究者扩展。原条件比较分为制度/信息27组、他人行为9组、收益条件18组；不是54个独立心理机制。701个合法四元组引用2804个条件，全局去重得到1240份输入。

新增18组比较复用同一来源已有游戏端点，许多提示也被其他比较复用。这增加比较覆盖，不凭空创造18项独立研究。两层共享204份输入，执行时只调用一次。

## 2. 对旧方案的实质修正

| 构建时发现的问题 | 实际处理 | 对论文解释的影响 |
|---|---|---|
| PIQ mini UG拒绝收益容易误套常见UG | 根据原游戏树，拒绝后双方各得10点；equal分支直接结束 | 不再混用不同UG的规则 |
| 原SPD第二行动节点用了不同方向标签 | 两侧统一中性X/Y，保留原动作映射 | 避免他人行动干预同时更换模型输出编码 |
| 原游戏使用中性行动标签 | PIQ提示仅给方向/中性字母与收益，“合作”等只存分析映射 | 避免自行加入道德框架 |
| 只靠新增干预，真实比较覆盖不足 | 纳入TG两条R变化序列、UG相邻分配条件，参数从源表核对 | 增加原条件证据；仍不声称纯心理机制识别 |
| PGG取整均值与策略表性质容易丢失 | 明确填写假设条件表一格，保留随机Y角色、未知贡献和T5独立信号 | 不用3c还原总贡献，也不假装已观察条件值 |
| TPP平均提议与逐人成本容易混淆 | 共同方案决定每位提议者收益，惩罚逐人计算 | 群体与个人同时改变总扣减，不能只归因于责任分散 |
| TPP提议5点后收益3.5的舍入未知 | 剔除该条件，不采用语言或程序默认舍入 | 留下明确可复入条件，不生成模糊“真值” |
| Econ DG存在50/50付款角色安排 | 明确固定当前分配者支付分支，完整记录改编 | 不把模型给予率当原调查的直接复刻 |
| Econ TG实际为两次翻倍，返还为事前计划 | 保留两次翻倍和未知既有计划；已实现单节点返还另记改编 | 不误套常见三倍信任游戏 |
| “自然段变体”可能只删项目符号 | 角色字段采用明确句式转换并连接成自然段，情境基准也真正连接 | 名称与实际操作一致；句式转换仍需语义复核 |
| 多来源同任务标签不一致 | 将trust_game/trust、ultimatum_game/ultimatum及对应角色统一编码 | 统一汇总，不因来源命名不同拆成虚假任务 |
