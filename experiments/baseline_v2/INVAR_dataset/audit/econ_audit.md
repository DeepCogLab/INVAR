# Econographics构建核验与适用范围

核验日期：2026-10-22。材料为此前实际下载的原始问卷设计文件、数据及Dataverse元数据；本记录是AI辅助来源核验与程序检查，**不是研究者双人审核**。

## 1. 使用的材料

- 研究：[Chapman等，Econographics](https://doi.org/10.1086/723044)。
- 数据：[Harvard Dataverse，IGVOFO，v1.0](https://doi.org/10.7910/DVN/IGVOFO)，下载时元数据标记CC0 1.0。
- 直接刺激依据：[WEP Robust Econographics Survey Document FINAL.pdf](https://dataverse.harvard.edu/api/access/datafile/6573547)，本地位于`research/evidence/IGVOFO/`，以印刷页码定位。
- 相关位置：III.I Q1，p.21；Q2与Q3a-e，p.22；Q3f及付款实现，p.23；IV.B匹配，p.44。原文写“已参与调查者”的既有回答用于匹配，不能把所有回应描述为实时双人互动。
- 正式模块没有复制、导出参与者个人记录，也没有把其动作作为标准答案；只借用经过核验的题目规则、菜单和收到额。

## 2. 本轮实际产物

`builders/econ.py`提供标准库函数`build_pairs(root)`，返回8组比较：1组独裁者分配、1组信任送出、6组信任返还。每一组都标记为`researcher_extension`，干预来源为`researcher_constructed`，方向依据为`null`，人类标签禁用。

数量来自原题：独裁者1题、信任送出1题、返还条件表6格。增加返还额不能形成6项独立社会机制；这6格属于同一协议的条件变化。

## 3. 原方案需要修正的细节

### 独裁者付款不等于固定分配者

原问卷p.23规定：题目被选作付款时，50%按受访者自己的保留额付款；50%按另一位受访者分配给自己的金额付款。因此原调查行为不应直接等同于一个无角色不确定性的固定分配者博弈。

本模块明确固定自己的分配付款分支，提示只告知当前有效事实：“付款角色已确定为分配者，你本次实际获得的点数按你作出的分配结算。”原50/50抽签与改编差异在来源元数据中完整保留，不把原问卷背景塞入模型刺激。结果必须称为“基于Econographics规则的角色条件化改编”，不能直接与原人类给予率比较。

阈值1200点是预先方案中的研究者选择。合法菜单仍为0、1000、…、6000，所以它恰好使0与1000两个动作造成双方0收益，2000及以上照常执行。该规则不是受款者行使拒绝权，也不是原研究处理。阈值可以用于检测制度改变后响应是否依赖模板，**不能给出真人方向真值，也不能用它证明模型理解了公平或真实社会规范**。

该干预不应承担论文主要社会机制证据：自动阈值本身含有明显的规则执行与收益计算成分。保留为扩展层比为了覆盖独裁者范式将其并入实证核心层更诚实。

### 信任博弈是两次翻倍

送出s，受款者收到2s；受款者返还r，原送出者收到2r。收益为送出者`6000-s+2r`，受款者`2s-r`。这不是常见的送出乘三或返还不增值版本。

固定返还收到额50%的干预意味着r=s；送出者最终`6000+s`，受款者`s`。这个干预同时取消受款者自主性、消除送出者对返还额的不确定性，不能作为纯粹“信任强弱”的单因素心理实验。模块将它明确标记为“返还制度”变化，并不给预期方向标签。

原Q2按匹配对象已预先填写的条件返还计划结算；基线提示保留这一点，不声称匹配对象现在才选择。扩展条件则由公开规则自动执行，不再说对方可在0…2s中自由选择，从而避免规则自相矛盾。

### 返还题没有证据证明原表单只允许整数

原Q3a-f的文本框仅写允许0至收到额，未写整数限制。实际下载数据中的返还值表现为整点，不能据此反推表单不允许小数。

为与当前统一接口兼容，本模块明确将回答精度规定为整点：提示、行动空间与改编记录三处一致。它是本研究的精度选择，不是已核验的原题属性；不能声称完全复制原表单。若未来接口支持任意小数，应单独升级数据版本，不能悄悄改行动范围。

返还6对还从事前策略表变为已发生转移的一次角色决策。原Q3结算随机抽取一格；本题显式固定当前金额。保持金额、权限与收益一致，只比较初次转移为对方自主选择或程序强制指定。即便出现返还差异，也只能说与行动来源敏感性相容，不能排除归因、公平预期或强制规则带来的其他解释。

## 4. 构建后的规则检查

- 独裁者：七项动作与七项收益逐一对应，干预后只改变执行规则及必然后果；双方不新增拒绝或协商权。
- 信任送出：0送出时收到与返还均为0；最大送出6000、固定返还6000时，P1得12000、P2得6000。
- 信任返还：每一格的合法范围为0…2s，归一化分母固定为2s；两侧收益函数完全相同，端点均非负；P1最初6000、暂时保留6000−s均告知模型。
- 关系改写只改变一条对应叙述，保留转移来源、方向、点数、角色及行动权限，不把“自主”换成“收到”后省略意图信息。
- `build_pairs`会核对已归档原文中的章节、双倍返还、返还上界和50%付款文字；文件缺失或不符合预期时停止，而非静默继续。

## 5. 对整体研究的实质限制与建议

1. **不能预先保证数据会“验证出问题”。** 要构建能够检验基础可靠性的材料，同时允许模型不出现显著缺陷。不能根据先导模型表现删去没有效应的题或改干预阈值。
2. **分清描述可靠性和心理真实性。** 事实相同的输入呈现会造成差异是可检验的；这并不自动说明模型缺乏社会机制理解。模板效应可能包含一般阅读、注意分配和格式敏感性。
3. **干预零响应不自动构成失效。** 自由社会决策存在多种合法偏好；没有人类可比处理或明确角色规则时，只能报告响应及其呈现依赖。新增制度干预尤其如此。
4. **G不是与E完全独立的新缺陷。** 在同一有界标量行动尺度上，`G = |(μD−μC)−(μB−μA)| ≤ |μD−μC|+|μB−μA| ≤ 2E`（E采用该尺度上的Wasserstein-1时）。实验二应强调方向翻转、结论可重复性及实际意义，不能用同一组差异重复论证两种独立能力。
5. **有限条件不等于大样本任务覆盖。** 六格返还和若干格式变体共享协议；报告协议级与条件级描述，不能用上千提示声称上千真实独立社会情境。
6. **共同提示复用产生相关性。** 不同变体共享A和C，也可能跨比较共享文本；统计重采样应按唯一提示重采样一次并回填各四元组，不能独立抽每个四元组造成伪精度。
7. **不以显著性代替效应大小。** 32次采样下单题概率差误差很大；配套同提示重复、区间与预先确定的实际差异阈值。模板、任务和模型多重比较须说明控制方式。
8. **先保留未通过人工复核的状态。** 程序通过与AI独立核对并不等于“经两名人类研究者审核”；后续可先做技术先导，论文冻结前完成并保存真实审核记录。

本模块足以用于检验适配任务内的输入稳定性与干预结论稳定性；不提供人类对齐分数，不支持“准确模拟真人”或“纯粹识别互惠机制”的结论。
